# Fabric-Defect-Detection
YOLOv8-based defect detection on 7-class dataset. Includes dataset preprocessing, balancing, augmentation, and training. Achieved high mAP with bounding box predictions. Supports validation/test evaluation, confidence-based predictions, and visualizations with heatmaps for defect localization. 
A better version of this can be found in the paper "Towards Transparent Industrial Inspection: Explainable AI-Based YOLOv8 Framework for Multi-Class Fabric Defect Detection", which can be accessed via the DOI: 10.5281/zenodo.17632736 (https://zenodo.org/records/17632736).
